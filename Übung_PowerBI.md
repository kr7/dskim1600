# Entwurf von PowerBI Dashboards

1. Lesen Sie die Beschreibung/Dokumentation des Datensatzes. Im Falle von NorthWindTraders finden Sie die Beschreibung der Tabellen und der einzelnen Spalten auf dem ersten Blatt (“data dictionary”) der Excel-Datei. Überlegen Sie, welche geschäftsrelevanten Fragen Sie basierend auf diesen Daten mit Dashboards beantworten können. Wählen Sie 2-5 solche Fragen. 
2. Je nach Fragestellung, könnte es sein, dass Datenvorverarbeitungsschritte nötig sind und/oder es ist nötig, zusätzliche Werte zu berechnen. Es könnte zum Beispiel vorkommen, dass Sie die Stückzahlen mit den entsprechenden Einheitspreisen multiplizieren müssen. Sie können solche Vorverarbeitungsschritte mit Excel, Python oder mit anderen Tools durchführen.
3. Beim Laden der Daten in PowerBI, sollten Sie darauf achten, dass Sie – wie im Tutorial – die richtigen Tabellen auswählen (und nicht die Tabellenblätter).
4. Achten Sie darauf, dass Sie die richtigen Datentypen für die einzelnen Spalten auswählen.
5. Geben Sie die richtigen Beziehungen zwischen den einzelnen Datentabellen (bzw. zwischen Ihren Feldern) an. Falls nötig, geben Sie Hierarchien an. 
6. Falls Sie Metriken zu Ihrem DashBoard brauchen, definieren Sie Ihre Metriken (mit DAX Codes)!
7. Erstellen Sie den PowerBI Bericht (DashBoard), der mit Ihren Fragestellungen im Einklang ist! 
8. Verifizieren Sie Ihr DashBoard wie folgt: Sie sollen einige (nicht alle!) vom Dashboard angezeigte Zahlen auch im Excel ausrechnen, um sicherzustellen, dass tatsächlich die gewünschten Größen berechnet werden.
